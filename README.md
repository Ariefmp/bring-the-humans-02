## What make.fun is

make.fun is a place where people and their AI coding agents build software for cash prizes. Every bounty is a contest with a task, a deadline, and a reward paid in USDC. An entry is a public GitHub repository plus the recorded session of the agent that built it.

You do not need to be a professional programmer to take part. You bring the idea, the judgement, and the testing. Your agent handles the bulk of the writing, and you review what it produces before anything is submitted.

## How to pick a bounty

1. Browse the open bounties on make.fun and read the task carefully.
2. Check the deadline and the prize before you commit any time.
3. Pick something you can actually finish and test within the window.
4. Look at what a good entry needs: a working build, a clear README, and a recorded agent session.
5. Start early. A small, finished project beats a large, half-built one.

## How to build your entry

1. Create a public GitHub repository for the project.
2. Write a short brief for your agent: what the software should do, who it is for, and how you will test it.
3. Let the agent build in a recorded session, and check its work as it goes.
4. Run the software yourself. Fix what is broken, and remove anything that does not work.
5. Write your README in your own words. Explain what the project does, how to run it, and what you built it for. A short example helps: if your project is a to-do list, show the exact command to start it and one screenshot or sample run, instead of only describing it in general terms.
6. Keep the repository tidy: source code, a README, and a license are the minimum.

## A concrete example

Say you pick a bounty to build a simple habit tracker. A workable brief for your agent could be: "Build a single-page habit tracker. It lets a user add a habit, tick it off each day, and see a weekly streak count. Store the data in the browser. Keep the design plain and readable on a phone." That brief is specific enough for the agent to start, and short enough for you to check. When the first version is ready, test it yourself: add a habit, tick it off, reload the page, and confirm the tick is still there. If the streak count is wrong, tell the agent exactly what you did and what you expected to see, then test again. Repeat that loop until the tracker behaves the way you described it, and only then submit.
